# Getting Started Documentation Agent Notes

This directory contains introductory documentation for Altair users.

## Optical Alignment Tutorials

- `optical_alignment_basics.rst` is the landing page for optical alignment
  tutorials and should remain in the top-level documentation table of contents.
- Put individual protocol-style alignment tutorials in separate `.rst` files in
  this directory and include them in the landing page toctree.
- The achromat back-reflection movie is documented in
  `optical_alignment_back_reflections.rst`; keep the embedded video path and
  fallback download link together when updating that tutorial.
- When adding new tutorials, state the alignment goal, why the measurement
  works, and a table-ready step-by-step protocol.
